# 记忆模式

默认打开记忆模式，覆盖 100 道 Hot 100 算法题和 15 道多模态题。可按全部、Hot 100、多模态选择本轮题库；页面和编辑器共用主题与字号设置，初始主题为浅色。

记忆编辑器、题库编辑器与题解代码统一采用 `Consolas, "Courier New", monospace`，与 Windows 上力扣代码编辑器的字体设置一致。

代码统一使用粗体，默认 16px，顶部的字号按钮可在 12–24px 范围内调整；记忆模式、题库编辑器、补全菜单和参考题解即时同步。顶栏同时提供浅色 / 深色切换，浅色为白色与浅灰背景，深色为黑色与中性深灰背景。字号和主题保存在当前浏览器的 `acm-quick-drill:appearance-v1`，刷新后恢复，同源标签页同步；它们不触发提示或复习评分。浏览器禁止保存时显示提示。

所有 Python 编辑器和题解共用词法高亮与配色，采用 Light+ 风格（蓝色声明、紫色控制流、棕金函数、青色类型、绿色数字与注释），深色主题使用对应 Dark+ 颜色。两种模式共用 CodeMirror 编辑器，切换字号和主题不会重建代码文档或清除撤销记录。桌面端采用题目 / 代码分栏，窄屏采用单栏与可换行的顶栏。

- 每轮自行选择到期题数和新题数，到期题优先；未选择的逾期题继续保留。
- 每次新尝试从当前版本的空白模板开始；中途暂停、刷新恢复同一次尝试。
- 从顶部“添加题目”搜索并多选，按勾选顺序追加到当前轮末尾，总题数相应增加。候选题限定在本轮题库范围内，包括未学习的新题和本轮已跳过的题，排除已在队列中的题。主动重新加入会移除该题的跳过标记，防止与队列冲突；即使已有 FSRS 卡片或提示评分也可重新加入，历史记录和暂存草稿保留。暂停时也可添加；操作不替换当前尝试、不修改 FSRS 或提示记录，也不清空当前代码或通过状态。本轮已结束且仍有跳过题时，允许继续本轮，从新加入的第一题开始。重新默写使用全新空白模板，完成后正常评分，加入本身不评分。队列继续使用原有保存、导入、导出和跨标签页冲突处理；旧轮次按队列和跳过题中的题库类型推断范围。
- 算法题编辑器提供“公共辅助代码”入口，展示实际执行的 `prelude`、简短函数说明和复制按钮。查看不算提示，不修改当前代码；多模态结构检查不注入这些代码，因此不显示此入口。题库中“复用附录”统一改为“辅助函数由网站自动提供”。
- “跳过本题”将当前题移出本轮，保留已有 FSRS 记录，不新增评分或完成数量；从本轮选定题库补入尚未排入本轮的到期题或新题，优先继续原队列。单题轮次也可补入下一题；没有剩余可学题时结束本轮。跳过列表和题库范围随本轮保存，刷新后仍有效，下一轮重新参与选题。每题最近一次跳过的代码可在记忆首页“跳过的草稿”查看；不自动带入新的默写，完成该题评分后删除对应暂存草稿。导出与重置记忆均包含这些草稿。
- 输入模板不算提示。仅在记忆模式点击查看思路或答案时立即、且仅一次提交 Again。返回题库只暂停本轮，不记录提示，也不提交评分；已有提示记录保持不变。
- 核心思路和参考答案均支持编辑、保存、取消及“重置更改”。以题目和字段分别覆盖内置版本，保存在 `acm-quick-drill:solutions-v1`，题库、记忆模式和载入编辑器共用。重置单项需确认，不影响其他题解或学习进度；“重置记忆”保留这些自定义内容，学习记录导出不包含自定义题解。记忆模式仅在展开提示后提供编辑入口，保留原有 Again 记录。跨标签页同步，并在保存前核对当前字段，避免覆盖另一页面的新修改；保存失败保留正在编辑的内容。
- 记忆编辑器支持 Python 语法高亮、缩进参考线、自动缩进、括号配对及代码补全（自动弹出或 Ctrl+Space，Tab/Enter 接受，Shift+Tab 减少缩进）。补全仅使用 Python 常用名称和当前文档，不读取题解；编辑辅助不计为提示。每次切换尝试会清空编辑器撤销历史，避免恢复上一题代码。
- 算法题独立通过本站全部测试后可评 Hard、Good、Easy；多模态题独立完成并通过语法、接口、占位符结构检查后可评分。页面明确提示后者不验证张量数值和 shape，历史记录以 `validation: structure` 单独标记，不虚报测试数量。修改代码立即撤销通过状态。自定义输入不构成通过。
- FSRS-6 使用 ts-fsrs 5.4.2 官方实现，目标保持率 0.9，短期学习和重学步骤为 10 分钟，不启用随机扰动。保留 Card 状态、实际复习时间、原始 ReviewLog 和提示记录。
- 学习记录及当前尝试以单个 JSON 原子写入 `acm-quick-drill:memory-v1`。采用版本标记检测其他标签页的更新，提供导入/导出；不自动同步到服务器。
- 旧完成标记和练习草稿不转为记忆卡片。现有精简版草稿保留；迁移指纹只识别旧自动载入内容，不包含旧答案。
- 记忆首页底部提供“重置记忆”，两次确认后清空记忆卡片、复习历史与安排、未完成轮次、题库完成标记以及当前和历史代码草稿。任一步取消都不修改数据；可先导出记忆记录（不包含题库草稿和完成标记）。仅影响当前浏览器的当前网站，保留题库、题解、主题和字号。重置后回到初始记忆首页；同源已打开标签页会刷新，过期的运行结果、自动保存和导入不能恢复旧记录。

## 验证

```text
npm run typecheck
npm test
npm run test:answers
```

`public/review-tests.json` 包含 1,520 组固定测试，每题至少 6 组，来自已验证的边界与随机回归用例。浏览器使用 Pyodide 在独立 Python globals 和输入流中逐组执行，遵守每题 ACM 输出约定。这些测试不等同于力扣官方完整判题，也不能仅凭输出验证内部实现的复杂度或对象独立性。

`test:answers` 需要本地 Python 3.10+。使用网站本身不需要安装 Python。

分享版不包含个人学习记录或旧版答案备份。当前答案均为精简中文注释版；算法题入口统一为 `main()`，多模态题使用题目指定的函数 / 类接口。
